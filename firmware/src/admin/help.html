状态灯

蓝灯
慢闪等候连接，常亮表示蓝牙或热点已连接。
紫灯呼吸 · 绿灯常亮
紫灯表示正在处理操作，绿灯表示已成功设置模拟定位。
黄灯
两连闪表示待配对，呼吸表示完整备份等候 BOOT 确认。
白灯
启动短亮，恢复真实定位后闪两次。备份确认后短亮。
红灯三闪
操作失败。若反复三闪，表示盒子启动失败。

打开蓝牙页面

iOS 27 或更新版本。在「设置 → 隐私与安全性 → 开发者模式」开启开发者模式。

通过 Mac 接入或准备定位服务
  1. 连接 Mac

    用数据线将 iPhone 和盒子接到 Mac，解锁 iPhone。

  2. 运行接入助手

    在 Mac 双击 接入新iPhone.command，按提示信任电脑、开启开发者模式，并导入配对资料。

  3. 连接盒子热点

    完成后，iPhone 加入 盒子热点，使用热点密码，在 Safari 打开 192.168.71.1。

手机重启或升级后无法使用
把 iPhone 接回 Mac，运行 准备iPhone定位服务.command。

更换手机前先恢复旧手机真实定位。收藏、地图和 Wi-Fi 设置会保留。
