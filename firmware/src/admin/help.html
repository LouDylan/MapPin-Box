使用帮助

BOOT 短按
恢复真实定位。
BOOT 长按3秒
重新使用最近一次成功定位的地点。Google 地点在本次定位后10分钟内可重用，超时或重启后需从网页联网定位。
RST
重启盒子，保留配置；重启不会主动发送恢复定位指令。
连接与服务
操作时保持 iPhone 解锁并连接盒子。恢复真实定位并在苹果地图确认后，再断开电源。手机重启或系统升级后，可能需要接 Mac 重新准备定位服务。

完整备份

包含地图 Key、iPhone 配对资料、Wi-Fi 配置和地点记录，请妥善保管。

恢复时用 USB 将移点盒接到 Mac，运行 恢复盒子备份.command，将 .waypinbackup 文件拖入窗口并按提示确认。

状态灯

蓝灯
慢闪等候热点连接，常亮表示已有设备加入。
紫灯呼吸 · 绿灯常亮
紫灯表示正在处理操作，绿灯表示已成功设置模拟定位。
黄灯
两连闪表示待配对，呼吸表示完整备份等候 BOOT 确认。
白灯
启动短亮，恢复真实定位后闪两次。备份确认后短亮。
红灯三闪
操作失败。若反复三闪，表示盒子启动失败。

接入新 iPhone

当前手机：读取中

  1. 连接 Mac

    用数据线将 iPhone 和盒子接到 Mac，解锁 iPhone。

  2. 运行接入助手

    在 Mac 双击 接入新iPhone.command，按提示信任电脑、开启开发者模式，并导入配对资料。

  3. 连接盒子热点

    完成后，iPhone 加入 盒子热点，使用热点密码，在 Safari 打开 192.168.71.1。

更换手机前先恢复旧手机真实定位。更换配对会保留收藏、地图凭证和 Wi-Fi 配置。

手机重启或升级后无法使用
把 iPhone 接回 Mac，运行 准备iPhone定位服务.command。加入热点不会自动完成新手机的首次配对。
